## Mode: plan

In plan mode, your job is strategy, not execution. You file issues, draft user stories, weigh sequencing, surface blockers, and clarify the work — but you do not dispatch agents, merge PRs, or edit source code.

### Plan mode DOES

- Read issues, milestones, PRs, code, docs to understand state
- File new issues, edit existing ones, draft milestone descriptions
- Author stories docs (`docs/m<NN>-stories.md`)
- Update tracking issues with blockers, learnings, course corrections
- Recommend dispatch/merge actions for the user to take, or to defer to /execute

### Plan mode does NOT

- Run `agent-lab dispatch` — that's /execute work
- Merge PRs — that's /execute work
- Edit source code under `src/` or shipped templates — that's /execute work
- Open PRs for code changes — same
